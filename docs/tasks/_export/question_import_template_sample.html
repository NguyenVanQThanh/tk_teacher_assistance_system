Feature F-EXE-05 — Question Import

Quy tắc soạn file

  • Mỗi câu bắt đầu bằng "Câu N." (N = số thứ tự bất kỳ, chỉ để phân tách).
  • Thẻ độ khó ngay sau số câu: [NB] Nhận biết · [TH] Thông hiểu · [VD] Vận dụng. Không ghi thẻ → mặc định [NB].
  • Thẻ [TU] đánh dấu câu tự luận — bắt buộc có dòng "Đáp án: ...". Không có thẻ này → mặc định trắc nghiệm.
  • Câu trắc nghiệm: các dòng A./B./C./D. là đáp án. Đặt dấu * ngay đầu dòng đáp án đúng — bắt buộc đúng 1 dấu *, tối thiểu 2 đáp án.
  • Các câu cách nhau bằng 1 dòng trống.
  • Toàn bộ file bị từ chối nếu có bất kỳ câu nào sai quy tắc (không import một phần).
Câu 1. [NB] 2 + 2 x 3 bằng bao nhiêu?
*A. 8
B. 12
C. 6
D. 10

Câu 2. [TH] Nghiệm của phương trình x + 5 = 0 là?
*A. x = -5
B. x = 5

Câu 3. [VD] [TU] Trình bày cách giải phương trình bậc nhất một ẩn.
Đáp án: Chuyển vế, quy đồng, rút gọn ẩn số.

Ví dụ lỗi (file bị từ chối toàn bộ)

Câu 2. [TH] Nghiệm của phương trình x + 5 = 0 là?
A. x = -5
B. x = 5

→ Thiếu dấu * đánh dấu đáp án đúng ở Câu 2 → lỗi ERR-EXE-IMPORT_INVALID_QUESTION, toàn bộ file (kể cả Câu 1, Câu 3 hợp lệ) đều không được nhập vào hệ thống.
